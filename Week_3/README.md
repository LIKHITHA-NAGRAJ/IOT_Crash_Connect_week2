## 2. How to run
**Wokwi (ESP32-S3):** Wokwi has no folders. Create an ESP32-S3 Arduino project, copy every `.h`, `.cpp` and `.ino` file from `Firmware/` (all module folders) and `Tests/Test_Suites/` into it, and replace `diagram.json` with `Firmware/diagram.json`. Press Start. `sketch.ino` runs the suites and prints a summary. The integration suite simulates about two minutes. Turn suites off with the `RUN_...` flags at the top of `sketch.ino`.
**PC replay (optional):** build instructions are in `Tests/Replay_Tool/README.md`.

## 6. Pending questions and blockers
1. **Agreed flat telemetry schema** (field names, types, units, `sequence_number`, event message): needed before the packet builder can be aligned.
2. **Event contract:** `event_id`, `location_age_s`, `accident_type`, `confirmation_state`, `timestamp_utc` format (integer epoch versus ISO text), `gnss_fix_quality` type, device ID format, last-known location with age versus null-when-no-fix.
3. **SOS to dashboard:** backend endpoint and acceptance and dashboard check (not done).
4. Modem transport decision (modem TCP/MQTT versus PPP), APN and SIM, AT syntax verification.
5. PCB: pins, logic levels, modem power, antennas, IMU bus, SOS button circuit.
6. Policies: DEGRADED versus FAULT, GPS-first versus parallel acquisition, retry and queue policy, behaviour without GPS speed, false-positive mitigations.
7. Real thresholds (all placeholders) and the logged data to set them.
Full list: `Firmware/Design_Notes/Pending_Issues.md`.

## 7. Known limitations
- No real GNSS, IMU, modem, network, flash or physical button was used, and no accident-detection performance can be claimed.
- Telemetry is not flat and its timestamp is not yet an integer epoch; no event or telemetry was sent to the real backend.
- The detector has no filtering, mounting calibration or rest-offset estimate, and has two known false positives.
- The modem does not restart after a failure; there is no periodic loop, fault codes or modem restart policy.
- The flash model ignores wear and power loss, and the retry and queue policies are placeholders.
