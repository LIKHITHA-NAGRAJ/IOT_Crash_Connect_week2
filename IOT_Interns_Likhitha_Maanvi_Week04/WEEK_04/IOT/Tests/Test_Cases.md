All tests ran on a PC (g++ with the real TinyGPS++ source and a small Arduino stand-in). None ran on an ESP32-S3, in Wokwi, or with real GNSS, IMU, modem, button, battery or server.

Input type key: RECORDED = real NMEA captured in Week 1, SIMULATED = generated by the test, MOCK = scripted modem/server replies.
